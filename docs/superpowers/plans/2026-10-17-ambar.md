# Ambar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir Ambar, una PWA offline, privada y bilingüe (ES/EN) para superar adicciones: contador + hitos, SOS guiado, diario TCC, recaída compasiva, por qués/ahorro, progreso y PIN.

**Architecture:** SPA React + Vite. Toda la lógica de dominio son funciones puras en `src/lib/` (testeadas con Vitest); un único store Zustand persistido en `localStorage` las orquesta; los componentes solo leen el store y un hook `useNow` para el tic de 1 s. Contenido (catálogo de adicciones, teléfonos, hitos, textos) en `src/data/` y `src/i18n/`.

**Tech Stack:** Vite 6+, React 19, TypeScript estricto, Zustand 5 (`persist`), Tailwind CSS 4 (`@tailwindcss/vite`), Framer Motion (`motion` / `framer-motion`), vite-plugin-pwa, @fontsource-variable/fraunces + @fontsource-variable/inter, Vitest + @testing-library/react + jsdom.

**Spec:** `/mnt/almacen/AMBAR/docs/superpowers/specs/2026-10-17-ambar-design.md` (leer entero antes de empezar; manda sobre este plan en textos y comportamiento).

## Global Constraints

- Proyecto en `/mnt/almacen/AMBAR`. **Sin git**: no `git init`, no commits (regla del usuario). Los pasos "Checkpoint" sustituyen a los commits: ejecutar `npm run check` (tsc + vitest + eslint) y debe pasar.
- `tsconfig`: `"strict": true`, `"noUncheckedIndexedAccess": true`; prohibido `any` (regla eslint `@typescript-eslint/no-explicit-any: error`).
- Cero peticiones de red en tiempo de ejecución: sin Google Fonts, sin analíticas, sin CDNs. Único enlace externo: findahelpline.com, solo al pulsarlo.
- Persistencia: clave `ambar-store`, `version: 1`, `migrate` definido.
- Colores (CSS vars en `src/styles/theme.css`): oscuro por defecto — bg `#1a1715`, surface `#221d1a`, surface-2 `#26201d`, border `#2b2522`, text `#f3ece4`, muted `#a39589`, subtle `#9a8c7f`, accent `#e8b07a`, accent-2 `#f0c98f`, on-accent `#2a1a0c`. Claro — bg `#f7f2ea`, surface `#fffaf3`, surface-2 `#f1e8dc`, border `#e6dccd`, text `#2a2420`, muted `#6e6158`, subtle `#73665b`, accent `#94591f`, accent-2 `#b9783a`, on-accent `#fffaf3`.
- Tipos: serif Fraunces para cifras grandes/titulares emocionales; Inter para el resto; `tabular-nums` en contadores.
- Nada rojo en la UI de crisis. La palabra "fracaso"/"failure" no aparece en ningún texto.
- `prefers-reduced-motion` (o ajuste forzado) → animaciones sustituidas por fundidos.
- Todo texto visible pasa por i18n; ES es la fuente, EN debe tener exactamente las mismas claves (comprobado por tipos).
- Mobile‑first; en escritorio columna central `max-w-[480px] mx-auto`.

## Review Focus

1. **Fecha de inicio en el futuro** (onboarding o edición): debe rechazarse/limitarse a "ahora"; `getElapsed` nunca devuelve negativos → test en Task 2.
2. **Pestaña en segundo plano o móvil dormido horas**: el contador debe mostrar el tiempo real al volver (derivado de `Date.now()`, no de acumular tics) y celebrar solo el hito más alto pendiente → tests en Task 2 y Task 8.
3. **Días del calendario y cambio de hora (DST) / medianoche local**: agrupar por fecha local `YYYY-MM-DD`, no por UTC → test en Task 3.
4. **Importar un JSON corrupto o de otra forma**: no debe romper ni sobrescribir datos; mensaje amable → test en Task 4.
5. **`localStorage` no disponible (modo privado) o lleno**: la app debe seguir funcionando en memoria, con aviso discreto en Ajustes → test en Task 4.
